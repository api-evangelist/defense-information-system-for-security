# Defense Information System for Security (DISS)

> DISS is the enterprise-wide United States Department of Defense system of record for personnel
> security, suitability, and credentialing management for military, civilian, and contractor
> personnel. It is operated by the Defense Counterintelligence and Security Agency (DCSA) and
> replaced the Joint Personnel Adjudication System (JPAS) as the system of record on 31 March 2021.

## What an agent needs to know first

DISS **does not expose a public API**. There is no developer portal, no OpenAPI or other
machine-readable contract, no SDK, no MCP server, no agent card, and no sign-up. Access to DISS is
granted through a United States Government account-provisioning and authorization process to
DoD, federal, and cleared-contractor security personnel. It is not something an agent, a developer,
or a member of the public can call, purchase, or obtain a key for.

If you are an agent looking for a callable interface here: there is none, and none is expected.
Do not attempt to reach DISS programmatically.

## Provenance of this file

This llms.txt was **generated by API Evangelist** from its own third-party catalog record. It was
not published by DCSA and is not a document DCSA serves. As of 2026-09-07 the dcsa.mil edge
(AkamaiGHost) returns HTTP 403 to every automated request, including `/robots.txt` and `/llms.txt`,
so whether DCSA publishes an llms.txt of its own could not be determined.

## What this repository contains

- `apis.yml` — the APIs.json catalog record for DISS.
- `security/` — probed TLS/DNSSEC/SPF/DMARC posture for dcsa.mil, plus vulnerability-disclosure and
  trust-center probes (no program found).
- `well-known/` — the well-known discovery probe log. Every path returned HTTP 403; no document was
  recovered, and no `WellKnown` or `SecurityTxt` claim is made.
- `plans/`, `rate-limits/` — honest zeros. No plans and no published rate limits exist, because no
  public API exists.

## Not present, and why

- `openapi/`, `asyncapi/`, `graphql/`, `grpc/`, `wsdl/` — no machine-readable contract is published.
- `mcp/`, `a2a/`, `skills/` — nothing to derive from and nothing served; an agent card in particular
  is never authored on a provider's behalf.
- `packages/`, `cli/`, `sandbox/`, `changelog/` — no first-party client library, CLI, sandbox or
  developer changelog was found in any public registry or on any public page.
